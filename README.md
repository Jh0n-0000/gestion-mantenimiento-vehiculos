# Control de Mantenimiento de Vehículos

Proyecto final de Vue 3 realizado como una aplicación sencilla para registrar vehículos y sus mantenimientos.

## Tecnologías
- Vue 3
- Vite
- Vue Router
- Axios
- JSON Server
- JavaScript

## Requisitos de la práctica
- Dos entidades relacionadas: Vehículos y Mantenimientos.
- CRUD completo para ambas entidades.
- Buscador de vehículos por placa, marca o modelo.
- Filtro de mantenimientos por vehículo.
- Backend con JSON Server.
- Variable de entorno para la URL de la API.
- Ruta protegida mediante autenticación.

## Inicio
```bash
npm install
npm run serve
```

La aplicación se abre en http://localhost:5173 y el backend funciona en http://localhost:3000.
